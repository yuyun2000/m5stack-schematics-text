## 描述

**ToughC5** 是一款户外防水型物联网控制器。基于 ESP32-C5HR8 核心主控，搭载 **RISC-V** 32 位单核处理器，主频 240MHz，配备 16MB Flash 与 8MB PSRAM。支持 2.4 & 5 GHz 双频 Wi-Fi 6、BLE 5 以及 IEEE 802.15.4（Zigbee、Thread）多协议连接，可满足不同网络场景下的接入需求。
集成 2.0" 彩色 LCD 显示屏（分辨率 320 × 240），配备高灵敏电容触控面板；板载蜂鸣器、microSD 卡槽和 RX8130CE 实时时钟。外壳采用 PC + ABS（加 UV 粉）材质，具备抗紫外线老化能力。设备内部提供 I2C、GPIO、UART、RS485 扩展接口，以及电池接口，可通过机身两侧的 M12 接口对外引出，实现更多扩展功能。系统采用 M5PM1 + M5IOE1 实现多级电源管理，支持低功耗唤醒。设备支持常规防水防尘（非浸泡式防护），适用于户外边缘数据采集、智能楼宇、工业网关等多种应用场景。

## 产品特性

- ESP32-C5HR8 核心主控
  - 16MB Flash
  - 8MB PSRAM
  - 2.4 & 5 GHz 双频 Wi-Fi 6
  - 支持 BLE 5 / IEEE 802.15.4（Zigbee、Thread）
- 人机交互
  - 2.0" LCD 电容触控屏幕，分辨率 320 x 240
  - 板载无源蜂鸣器
- 时钟与电源
  - 板载 RX8130CE RTC 时钟
  - RTC 时钟电池（CR2032 纽扣电池 DC 3V@220mAh）
  - M5PM1 + M5IOE1 多级电源管理
  - DC 3.7V 电池接口
- 接口与扩展
  - USB Type-C 调试 / 程序下载
  - 内部接口扩展板: HY2.0-4P x 4 (RS485/I2C/GPIO/UART)
  - 2x M12 机身走线孔位
  - microSD 卡槽
- 便捷接线，磁吸安装
- PC + ABS（加 UV 粉）外壳材质，抗紫外线老化

## 管脚映射

### LCD

| ESP32-C5HR8 | G25 | G26 | G7   | G8   | G9  |
| ----------- | --- | --- | ---- | ---- | --- |
| ILI9342C    | CS  | DC  | MOSI | MISO | SCK |

通过 `M5IOE1` 扩展芯片的 `PYG5 (PYB_LCD_EN)` 控制屏幕使能，`PYG4 (PYB_LCD_RST)` 控制屏幕复位。

### microSD

| ESP32-C5HR8 | G7   | G8   | G9  | G10 |
| ----------- | ---- | ---- | --- | --- |
| microSD     | MOSI | MISO | SCK | CS  |

通过 `M5IOE1` 扩展芯片的 `PYG6 (PYB_TF_EN)` 控制 microSD 卡槽使能，`PYG14 (PYB_TF_DET)` 检测 microSD 卡插入状态。

| PYG14_PYB_TF_DET | Status       |
| ---------------- | ------------ |
| LOW              | Inserted     |
| HIGH             | Not Inserted |

### Touch

| ESP32-C5HR8 | G2  | G3  |
| ----------- | --- | --- |
| CHSC6540    | SDA | SCL |

通过 `M5PM1` 电源管理芯片的 `PMG0 (PM_TP_INT)` 捕获触摸屏中断信号输入，`PYG2 (PM_TP_RST)` 控制触摸驱动芯片复位。

### I2C Devices（TP & M5IOE1 & M5PM1）

| ESP32-C5HR8     | G2  | G3  |
| --------------- | --- | --- |
| CHSC6540 (0x2E) | SDA | SCL |
| M5IOE1 (0x4F)   | SDA | SCL |
| M5PM1 （0x6E）  | SDA | SCL |

### RS485

| ESP32-C5HR8   | G23      | G24      |
| ------------- | -------- | -------- |
| SP485EEN-L/TR | RS485_RX | RS485_TX |

### M5PM1

| M5PM1       | PYG0      | PYG1         | PYG2      | PYG3       | PYG4         |
| ----------- | --------- | ------------ | --------- | ---------- | ------------ |
| TOUCH       | PM_TP_INT |              | PM_TP_RST |            |              |
| ESP32-C5HR8 |           | PM_G1_IRQout |           |            |              |
| RTC         |           |              |           | PM_RTC_INT |              |
| BUZZER      |           |              |           |            | PM_BUZZER_EN |

- PYG0(PM_TP_INT): 触摸屏中断唤醒信号
- PYG1(PM_G1_IRQout): 连接至 ESP32-C5 的中断输出信号
- PYG2(PM_TP_RST): 触摸屏复位
- PYG3(PM_RTC_INT): RTC 中断唤醒信号
- PYG4(PM_BUZZER_EN): 蜂鸣器驱动信号

### M5IOE1

| M5IOE1  | PYG1         | PYG3         | PYG4        | PYG5       | PYG6      | PYG10     | PYG14      |
| ------- | ------------ | ------------ | ----------- | ---------- | --------- | --------- | ---------- |
| CHARGE  | PYB_CHG_PROG | PYB_CHG_STAT |             |            |           |           |            |
| LCD     |              |              | PYB_LCD_RST | PYB_LCD_EN |           | PYB_BL_EN |            |
| microSD |              |              |             |            | PYB_TF_EN |           | PYB_TF_DET |

- PYG1(PYB_CHG_PROG): 充电电流控制
- PYG3(PYB_CHG_STAT): 充电状态检测
- PYG4(PYB_LCD_RST): LCD 屏幕复位
- PYG5(PYB_LCD_EN): LCD 屏幕使能
- PYG10(PYB_BL_EN): LCD 屏幕背光驱动信号
- PYG6(PYB_TF_EN): microSD 卡槽使能
- PYG14(PYB_TF_DET): microSD 卡槽插入状态检测

| PYG1_CHG_PROG | CHARGE CURRENT  |
| ------------- | --------------- |
| LOW           | 650mA           |
| HIGH          | 180mA (Default) |
