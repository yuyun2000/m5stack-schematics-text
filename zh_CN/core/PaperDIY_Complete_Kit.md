## 描述

**PaperDIY Complete Kit** 是一款墨水屏开发板套件，标配主控板、墨水屏与 3D 打印外壳，出厂已完成硬件装配；主控板采用 ESP32-S3R8 核心主控，标配 16MB Flash + 8MB PSRAM 内存组合，支持 2.4 GHz Wi-Fi 连接。套件搭载 4.7" 电子墨水屏，分辨率 960×540，支持 16 阶灰度显示。板载电池接口、microSD 卡槽与 USB Type-C 接口，内置 140mAh 锂电池。配套开源模型文件，支持用户重制外壳或自主调整设计，适合搭建桌面信息屏、电子标签、创客 DIY 项目与嵌入式硬件开发实验。

## 产品特性

- ESP32-S3R8 核心主控：
  - 16MB Flash 
  - 8MB PSRAM
  - 2.4 GHz Wi-Fi
- 4.7" 电子墨水屏 960×540 分辨率
- 16 阶灰度显示
- 板载 DC 3.7V 电池接口，内置 140mAh 锂电池
- microSD 卡槽
- 低功耗电源管理设计
- 标配 3D 打印外壳，外壳模型开源，支持重新打印与自定义修改

## 操作说明

### 电源按键操作

- 单击：开机 / 复位
- 双击：关机
- 长按：进入下载模式

<img src="https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1288/K159-B_PaperDIY_Complete_Kit_pwr.png" width="60%">

### 进入下载模式

如需烧录固件，请将设备通过 USB Type-C 数据线连接至电脑，长按电源按键（大约 2 秒），直到红色 LED 闪烁后松开按键，表示设备已进入下载模式，等待烧录。

### E-Paper

| ESP32-S3 | G6      | G14     | G7      | G12     | G9      | G11     | G8      | G10     |
| -------- | ------- | ------- | ------- | ------- | ------- | ------- | ------- | ------- |
| ET047TC1 | EPD_DB0 | EPD_DB1 | EPD_DB2 | EPD_DB3 | EPD_DB4 | EPD_DB5 | EPD_DB6 | EPD_DB7 |

| ESP32-S3 | G16     | G15     | G13      | G18     | G17     | G46    |
| -------- | ------- | ------- | -------- | ------- | ------- | ------ |
| ET047TC1 | EPD_XCL | EPD_XLE | EPD_XSTL | EPD_CKV | EPD_SPV | BST_EN |

通过 `M5PM1` 电源管理芯片的 `PYG2 (EPD_PWR)` 控制电子墨水屏及其驱动电路供电，`G46 (BST_EN)` 控制墨水屏升压电路使能。

### microSD

| ESP32-S3 | G40       | G47     | G39      | G38       | G48      |
| -------- | --------- | ------- | -------- | --------- | -------- |
| microSD  | CARD_MISO | CARD_CS | CARD_SCK | CARD_MOSI | CARD_DET |

### Button

| ESP32-S3 | G4              | G3              |
| -------- | --------------- | --------------- |
| KEY      | KEY1（ButtonA） | KEY2（ButtonB） |

电源按键连接至 `M5PM1` 电源管理芯片的 `PY_BTN (BTN_PU)` 引脚。

### M5PM1

| ESP32-S3 | G42     | G41     |
| -------- | ------- | ------- |
| M5PM1    | SYS_SCL | SYS_SDA |

| M5PM1   | DCDC3V3_EN_PP | CHG_EN_PP | BAT_ADC_EN_PP |
| ------- | ------------- | --------- | ------------- |
| 3V3_L2  | PY_MPWR_EN    |           |               |
| Charge  |               | CHG_EN    |               |
| Battery |               |           | BAT_ADC_EN    |

| M5PM1              | 5VIN_ADC_IN | BAT_ADC_IN |
| ------------------ | ----------- | ---------- |
| Voltage Monitoring | USB_ADC     | BAT_ADC    |

| M5PM1     | PYG0  | PYG1  | PYG2    | PYG3     | PYG4  |
| --------- | ----- | ----- | ------- | -------- | ----- |
| FPC - I2S | PY_G0 |       |         |          |       |
| FPC - SPI |       | PY_G1 |         |          | PY_G4 |
| E-Paper   |       |       | EPD_PWR |          |       |
| Charge    |       |       |         | CHG_STAT |       |

- PYG0(PY_G0): FPC - I2S 接口扩展信号
- PYG1(PY_G1): FPC - SPI 接口开关信号
- PYG2(EPD_PWR): 电子墨水屏及其驱动电路电源使能
- PYG3(CHG_STAT): 充电状态
- PYG4(PY_G4): FPC - SPI 接口复位信号
